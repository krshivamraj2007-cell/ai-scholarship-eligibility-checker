# AI Scholarship & Government Scheme Eligibility Checker

An AI-powered web application that helps students
discover scholarships and government schemes based
on their eligibility criteria.

## Features

- Student Profile Management
- Scholarship Eligibility Checking
- AI-Powered Assistant
- Personalized Scheme Recommendations
- Document Checklist
- Application Deadline Tracking

## Technology Stack

- Frontend: React
- Backend: Python (FastAPI)
- Database: PostgreSQL
- AI: AI API

Development in Progress.
